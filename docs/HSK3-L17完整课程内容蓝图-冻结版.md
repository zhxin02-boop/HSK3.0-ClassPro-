## 5. 四个语法点的渐进式设计

四点统一使用 `presentationMode: progressive_grammar`、`mergeNoticeObserve`、`observeMode`、`observePrompt`、逐例对应的 `observeHighlights`、`visualLearning`、`oralQuestions`、`structureVariants` 和图片型 `followUp`。每点至少5条例句，教材例句保留并标记 `textbook`，新增例句标记 `teaching_extension`。

### 5.1 `g17_01` 介词“向”

- 观察情境：动作朝向一个地方，或一个人向另一个人学习、提问。
- 教材例句：
  1. 别再向前走了。
  2. 以后我要多向认真的人学习。
  3. 孩子一看见妈妈，就向她跑过去了。
- 教学扩展示例：
  4. 我想向同桌学习，因为他做事很认真。
  5. 有问题的时候，我会向老师请教。
- 结构归纳：`向 + 地方/人 + 动作`。
- 结构变体：向＋方向＋移动；向＋人＋学习/请教/介绍。
- 课堂表达：你想向谁学习？你遇到难题时会向谁请教？
- 跟进图片：`photo-text-1-careful-work.png`。
- 跟进目标：使用“向＋人＋学习”说出榜样和理由。
- 示例答案：我想向右边的同学学习，因为他做完以后会认真检查。

### 5.2 `g17_02` 反问句“不是……吗？”

- 观察情境：朋友根据已经知道的信息提醒或提出建议。
- 教材例句：
  1. 你不是喜欢玩电脑吗？你可以去看看跟电脑有关系的书。
  2. 你不是说今天有事吗？你怎么来了？
  3. 考试不是下个月吗？你怎么今天就开始复习了？
- 教学扩展示例：
  4. 你不是想继续学习吗？我们一起去图书馆看看吧。
  5. 你不是对设计感兴趣吗？可以先查一查有关的课程。
- 结构归纳：`主语 + 不是 + 已知情况 + 吗？`；常接提醒、确认或建议。
- 使用提醒：语气可能表示不理解或不满；给同学建议时应保持友好语气。
- 课堂表达：同学想学电脑但不知道看什么书，你怎样提醒他？朋友忘了带已经准备好的材料，你怎样确认？
- 跟进图片：`photo-text-2-computer-books.png`。
- 跟进目标：用“不是……吗？”给出一个友好提醒，再补一句建议。
- 示例答案：你不是喜欢玩电脑吗？可以先看看这些有关的书。

### 5.3 `g17_03` 递进复句“……，更……”

- 观察情境：第一个想法还没有确定，第二个问题比第一个更难确定。
- 教材例句：
  1. 我还没想好学什么，更没想好去哪个国家。
  2. 想提高中文水平要多听多看，更要多说多练。
  3. 来中国学习，我学会了中文，更了解了中国文化。
- 教学扩展示例：
  4. 选学校要看课程，更要看这个方向适不适合自己。
  5. 我想了解这个国家，更想知道那里的大学生活。
- 结构归纳：`分句1，+ 更 + 分句2`，第二部分比第一部分再进一步。
- 结构变体：没……，更没……；要……，更要……；会……，更……。
- 课堂表达：学好中文要做什么？选择留学地点时，你想先了解什么，更想了解什么？
- 跟进图片：`photo-text-3-study-abroad-search.png`。
- 跟进目标：用“……，更……”说出两层需要了解的信息。
- 示例答案：我想先了解学校的课程，更想了解这个方向适不适合我。

### 5.4 `g17_04` 条件复句“只有……，才……”

- 观察情境：从多个选择中先确定不可少的条件，再做决定。
- 教材例句：
  1. 只有想清楚自己真正喜欢什么，才能做出最合适的选择。（已按用户确认勘误）
  2. 只有每天锻炼身体，才会越来越健康。
  3. 只有多听、多说、多看，你的中文水平才能提高。
- 教学扩展示例：
  4. 只有查清楚课程和费用，我才会决定去哪里学习。
  5. 只有认真了解自己，我才能选择合适的方向。
- 结构归纳：`只有 + 必要条件，+ 才 + 结果`。
- 使用提醒：“只有”后是不可以少的条件；没有这个条件，“才”后的结果一般不能实现。
- 课堂表达：怎样才能选到适合自己的方向？怎样才能真正提高中文水平？
- 跟进图片：`photo-text-4-next-step-plan.png`。
- 跟进目标：用“只有……，才……”说出做决定前的一项必要条件。
- 示例答案：只有先想清楚自己真正喜欢什么，我才能选择合适的方向。

## 6. 四篇课文的五阶段设计

每篇固定呈现：

1. 听/读：播放教材音频，只找人物、地点、主要问题或最后决定，不显示答案性细节。
2. 整体选择：恰好3题，使用“谁、哪里、为什么、想做什么、最后怎么做”等简单题干。
3. 细节问答：恰好5题；实现时补齐稳定ID、题目拼音、标准答案、答案拼音、`acceptedAnswers` 和 `informationPoint`。
4. 展示课文：教材中文、拼音和英文原样保存；课文4使用日记/连续叙述布局。
5. 语言与应用：包含 `keyPoints`、`cultureDiscussion`、`retellScaffold`、`languageAndApplication`，并对齐对应MINI终点任务。

12道整体题答案位置冻结为A/B/C各4题，同一答案位置不连续超过2题。题干禁用“谈、顺序、特点、交际目的、发展、状态、哪类”等抽象词。

预读问题：

2. 你觉得“聪明”和“认真”有什么不同？

- `cultureDiscussion.title`：做错以后，认真改进 / Learning from Mistakes。
- `cultureDiscussion.background`：Use simple English to explain that making a mistake does not mean a student is not smart. A useful response is to identify the cause, ask for help and change one action next time.

## 7. A/B/C预习设计

每次预习恰好5阶段，使用当前A/B/C标签，不把三次课机械复制成同一套题。

| 阶段 | Preview A：向谁学习 | Preview B：继续学什么 | Preview C：下一步计划 |
|---|---|---|---|
| 1 认识任务 | 向、楼梯、害怕、生气、聪明、错、认为；英文说明“mistake”和“careful action”的区别 | 到处、继续、同意、有关；英文说明“友好提醒＋实际建议” | 关机、前天、留学、国家、查、有用、方向、真正、难题；英文说明查资料与选择方向 |
| 2 认读/词义 | 看词或拼音选择向、害怕、生气、认为 | 看词或拼音选择继续、同意、有关、屋子 | 看词或拼音选择留学、国家、查、方向、难题 |
| 3 汉英匹配 | 6组错误、感受和学习对象核心词 | 6组图书馆、继续学习和建议核心词 | 8组调查信息和未来选择核心词 |
| 4 完整语境 | 判断谁做事认真，并补全“向＋人＋学习” | 选择友好语气的“不是……吗？”提醒并补一句建议 | 补全“……更……”和“只有……才……”的完整语境 |
| 5 正式挑战 | 10题：词义、课文1人物、出错原因和“向” | 10题：词义、课文2选择、建议语气和“有关” | 10题：课文3—4信息、查资料、递进和必要条件 |

预习状态键冻结为 `ClassProPreview_HSK3-L17_${session}_${student}_${contentVersion}`。内容版本不匹配时不得恢复旧答案。正式挑战记录 `lesson/session/student/score/total/accuracy/elapsedTime/wrongItems/submittedAt`；兼容旧报告时可额外写 `durationMs`，但不得替代 `elapsedTime`。必须验证返回、下一步、重做、刷新恢复和手机触控。

### 8.1 问答匹配三组主题

- 第1组：为什么在楼梯等／为什么害怕／错事是否常见／聪明人为何出错／以后向谁学习。

1. 《做完再检查一次》：聪明学生因没有检查而出错；问“他下次准备怎么做？”

3. 《两个学习计划》：比较课程和实际兴趣；问“哪一个计划更适合她？”
4. 《先查什么》：用学校资料、费用和生活信息做选择；问“文章建议先做什么？”
5. 《不同的毕业方向》：三位同学选择学习、留学或工作；问“为什么他们的选择不同？”

| 友好建议 | 朋友喜欢电脑但不知道学什么 | 用“不是……吗？”提醒并给建议。 | 电脑、有关、书 | 你不是喜欢玩电脑吗？可以先看看跟电脑有关的书。 |
| 查留学信息 | 学生还没决定国家和专业 | 用“更”说出两层需要了解的信息。 | 留学、国家、查 | 我想先查学校的课程，更想知道这个方向适不适合我。 |
| 三个方向 | 三位毕业生分别学习、留学、工作 | 用“比如”介绍不同选择。 | 方向、比如、回答 | 大家方向不同，比如有人继续学习，有人先找工作。 |
| 做出选择 | 学生面对几个未来计划 | 用“只有……才……”说必要条件。 | 真正、难题、只有 | 只有想清楚自己真正喜欢什么，才能选择合适的方向。 |

### 10.2 击鼓传词

- 教师可选起始句：“我想向……学习，因为……”“你不是……吗？可以……”“我还没想好……，更没想好……”“只有……，才……”“毕业以后，我打算……”。

- 关键词从本课正式词汇和4个语法点中取，不随机混入无关主题。

- 任务类型：词汇解释、完整句、课文事实、友好建议、语法改写、信息调查、未来选择、旧课复习。

## 12. Homework A/B/C

三次作业都提供Support、Core、Challenge三级支架；弱点与错题默认折叠，学生主动打开后才显示。

### Homework A：My Role Model Card

- 材料：一张自画、公开资料或隐私安全的榜样图片，也可以只用姓名/称呼卡。
- 必答问题：你想向谁学习？这个人做什么很认真？你想学习什么？
- 必用词：至少3个T1词汇。
- 必用结构：Core/Challenge使用“向＋人＋学习”；Support使用完整句框。
- 发言时间：30—45秒。
- 小组规则：两人互相听，每人必须说出“人＋理由”。
- Support：人物词库、优点词库和完整句框。
- Core：说出人物、一个具体行为和学习理由。
- Challenge：补充自己准备改变的一件小事。
- 产物ID：`post_l17_a_role_model_card`，`carryTo: B,C`。

### Homework B：Learning Direction Card

- 材料：Homework A卡、一本书或教师提供的一张课程/专业信息卡；不要求学生自行搜索陌生网站。
- 必答问题：你想继续学习什么？为什么？你已经有什么资料？你想请同学给什么建议？
- 必用词：至少4个T2词汇。
- 必用结构：Core/Challenge使用一次友好语气的“不是……吗？”或“跟……有关”。
- 发言时间：30—45秒。
- 小组规则：A说方向和问题，B给一条建议，然后交换角色。
- Support：方向词库和“我想继续学习……，可是……”句框。
- Core：完成3—4句方向介绍并请求建议。
- Challenge：用“不是……吗？”回应伙伴，但语气必须友好。
- 产物ID：`post_l17_b_learning_direction_card`，`carryFrom: A`，`carryTo: C`。

### Homework C：My Next Step Plan

- 材料：Homework A卡、Homework B卡、一张教师提供的国家/城市/学校信息卡或学生自制信息卡。
- 必答内容：介绍一个榜样；说明想学习的方向；介绍想去学习的地方和准备办法；说明毕业后想工作还是继续学习以及理由。
- 必用词：Support至少5个、Core至少7个L17词汇。
- 必用结构：Support可选择“更”或“只有……才……”；Core两种结构都使用；Challenge再复现“向”或友好语气的“不是……吗？”。
- 发言时间：1—2分钟，主要在课堂展示，不上传音频。
- 小组规则：小组可共用信息卡，但每名学生必须完成有意义的发言；同伴只帮助检查，不代写。
- Support：四步顺序卡“向谁学习→想学什么→怎么准备→工作还是继续学习＋理由”和完整句框。
- Core：实际复用A的榜样材料和B的学习方向，形成下一步计划。
- Challenge：比较两个可能方向，并说明最终决定需要什么条件。
- 产物ID：`post_l17_c_next_step_plan`，`carryFrom: A,B`。

英文课堂说明必须明确写出要带什么、回答什么、使用哪些词/结构、发言时长、小组规则和“No audio upload is required”。
