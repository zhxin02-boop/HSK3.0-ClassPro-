# HSK3-L01 课中生词真实配图清单

## 配图原则

- 只给适合视觉化的实物、人物外貌、场景动作类生词配图；抽象词不强行配图。
- 图片使用真实场景或写实照片风格，优先横版 16:9。
- 关键对象必须完整保留，不能裁掉头、脸、证件、行李、箱子等核心信息。
- 图片中尽量不出现可读文字、品牌、真实证件信息和水印。
- 每张图只表达一个核心词义，避免同一张图重复用于多个词。
- 课中讲解页图片用于辅助理解，不代替词卡主体信息。

## 暂不配图

| 生词 | 原因 |
| --- | --- |
| 以为 | 抽象心理动词，不适合直接配图 |
| 长 | 抽象/多义动词，易和外貌形容混淆 |
| 重要 | 抽象判断词 |
| 好像 | 抽象判断词 |
| 应该 | 情态表达，不适合单图呈现 |
| 发现 | 抽象认知动作，容易误导为“看见” |

## 后续执行标准

1. 先生成或搜集 3 张样图，确认风格后再批量补齐。
2. 图片落位到 `source/in-class/images/vocab/hsk3-l01/real/`。
3. 只替换已确认准确的词，不准确的词继续保留无图词卡。
4. 每次替换后检查讲解页：图片不裁切关键部分，汉字、拼音、英文、短语、例句仍为主体。
