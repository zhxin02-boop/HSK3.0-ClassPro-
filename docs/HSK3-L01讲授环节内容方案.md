# HSK3-L01 讲授环节内容方案

> 目标：先确定 HSK3-L01 的 `讲 / Teach` 环节框架和样板内容，再进入 `练 / Practice` 的题型升级。  
> 当前处理重点：A 段课文一，主题为“去机场接朋友、描述人物外貌、看起来/看上去”。

## 一、四环节保留原则

HSK3 仍保留 ClassPro+ 四个课中环节：

| 环节 | HSK3 定位 | 当前处理状态 |
|---|---|---|
| 讲 | 教师主导的输入、发现、讲解和文本理解 | 今天重点确定 |
| 练 | 学生即时操练和题型互动 | 今天先梳理，后续新增题型 |
| 赛 | 小组或个人竞赛，复用核心语言点 | 暂保留现有 PK 框架 |
| 测 | 阶段性或课堂检测 | 暂保留现有测试框架 |

HSK3 的“讲”不再包含 HSK1 式拼音主模块。讲授页固定为：

1. 词汇 / Vocabulary
2. 语法 / Grammar
3. 课文 / Text

## 二、讲授环节总体框架

### 1. 词汇讲授

词汇讲授不以“认字、读音、书写”为中心，而以“能在本课任务里用出来”为中心。

每个词固定呈现：

- 大字
- 拼音
- 英文释义
- 场景配图
- 短语
- 例句

教师讲授重点：

- 这个词在什么场景中说
- 和哪些词自然搭配
- 本课哪句话用到了它
- 学生可以怎样替换使用

### 2. 语法讲授

每个语法点固定采用：

1. 场景：先给说话目的。
2. 发现：让学生观察共同结构。
3. 结构：给最小公式。
4. 例句：从本课到迁移。
5. 教师提示：使用边界和常见错误。

### 3. 课文讲授

课文模块不能只是显示课文和问答。HSK3 课文讲授应解决三个问题：

- 学生是否理解场景和人物关系
- 学生是否能抓住每段的关键信息
- 学生是否能把课文语言转化为自己的表达

每篇课文建议结构：

1. Scene：在哪里，谁和谁，说话目的是什么。
2. Who is Who：人物关系和信息缺口。
3. Read for Meaning：分段理解。
4. Language Links：回扣词汇和语法。
5. Class Q&A：投屏问题，先理解后表达。
6. Micro Output：一句话复述或角色任务。

## 三、L01 A 段词汇讲授内容

A 段对应课文一，目标不是把所有 HSK3-L01 生词讲完，而是先支撑“看照片、描述外貌、去机场接朋友”。

### 1. 以为

核心功能：表达“原来以为 A，后来发现不是”。

短语：

- 以为是
- 我还以为

例句：

- 我还以为是同乐呢。
- 我以为你今天不来。
- 他看起来很像我朋友，我以为是他。

教师提示：

- `以为` 后面通常接一个原来的判断。
- 课堂上可让学生看相似照片，先猜“我以为是……”，再揭示真实身份。

### 2. 像

核心功能：描述两个人或两件事物相似。

短语：

- 有点儿像
- 长得像
- 不像

例句：

- 他们看起来有点儿像。
- 这个人长得像我的朋友。
- 这张照片不像他。

教师提示：

- `像` 可以直接说相似，也可以和 `看起来/看上去` 配合。
- 区分 `像` 和 `好像`：`像` 多用于相似，`好像` 多用于不确定判断。

### 3. 长

核心功能：描述人的外貌形成或生长结果，A 段重点使用 `长得...`。

短语：

- 长得像
- 长得高
- 长得瘦

例句：

- 他们长得有点儿像。
- 他长得很高。
- 她长得不太像照片。

教师提示：

- 这里的 `长` 读 `zhǎng`，不是 `cháng`。
- `长得 + 形容词/像...` 用来描述人的外貌。

### 4. 身高

核心功能：说一个人的高度。

短语：

- 身高一米八
- 问身高
- 他的身高

例句：

- 他的身高是一米八。
- 你知道他的身高吗？
- 这个人的身高比我高一点儿。

教师提示：

- `身高` 是名词，常和 `是/有` 搭配。
- 课堂上可配合照片或人物卡进行猜测和比较。

### 5. 米

核心功能：长度单位，A 段用于说身高。

短语：

- 一米八
- 一米七五
- 两米

例句：

- 他身高一米八。
- 我身高一米六五。
- 那个人差不多两米高。

教师提示：

- 说身高时常省略小数点：`一米八` 表示 1.8 meters。
- 初学者容易把 `米` 当普通名词，教师要强调它是量词/单位。

### 6. 瘦

核心功能：描述外貌。

短语：

- 有点儿瘦
- 比我瘦
- 看起来瘦

例句：

- 他看起来有点儿瘦。
- 李文比同乐瘦一点儿。
- 这张照片里，他不太瘦。

教师提示：

- 课堂上要注意文化敏感度，避免让学生直接评价同学身材。
- 优先评价照片、角色或虚拟人物。

### 7. 接

核心功能：到某个地方见人并带他走，A 段重点是 `接朋友/接人`。

短语：

- 接朋友
- 去机场接人
- 来接你

例句：

- 我去机场接朋友。
- 明天我来接你。
- 下课以后，妈妈接我回家。

教师提示：

- `接` 不是简单的 `meet`，通常含有“去某地等人并带走”的意思。
- 可让学生说：我去机场/车站/学校接谁。

## 四、L01 语法讲授框架

### 1. 看起来 / 看上去

场景：

学生只有照片，需要根据外貌做判断。

发现：

比较：

- 他很高。
- 他看起来很高。

让学生发现第二句是“根据看到的样子判断”。

结构：

`人/物 + 看起来/看上去 + 描述`

例句：

- 他看起来很高。
- 他们看起来有点儿像。
- 这个箱子看起来很重。
- 那个年轻人看上去很着急。

教师提示：

- 不要先讲公式，先出图或人物卡。
- 强调这是视觉印象，不一定是确定事实。

### 2. 好像 + 不确定判断

场景：

在机场或行李区，学生觉得见过某个人/某个箱子，但不确定。

发现：

比较：

- 我在哪儿看到过这个箱子？
- 我好像在哪儿看到过这个箱子。

结构：

`主语 + 好像 + 不确定的信息`

例句：

- 我好像在哪儿看到过这个箱子。
- 他好像不是我要接的人。
- 她好像比照片上年轻。

教师提示：

- `好像` 后面是说话人的不确定判断。
- 后续可连接“疑问代词的非疑问用法”，但不要一次讲太重。

### 3. 多项定语

场景：

机场人很多，需要用多个特征锁定一个人。

发现：

一步步加信息：

- 年轻人
- 短头发的年轻人
- 穿着黑衣服的短头发的年轻人

结构：

`那个 + 特征1 + 的 + 特征2 + 的 + 人`

例句：

- 那个短头发的年轻人是李文吗？
- 那个穿着黑衣服的年轻人是我的朋友。
- 李文是那个穿着黑衣服的短头发的年轻人吗？

教师提示：

- 不要一开始给长串定语。
- 先让学生用一个特征找人，再逐步增加第二、第三个特征。

## 五、L01 课文讲授框架

### 课文一：我们去机场接你们

Scene：

- 地点：家里
- 人物：刘明、王一雪
- 任务：看照片，确认照片里的人是谁，并讨论去机场接人。

Who is Who：

- 杨同乐：刘明以为照片里的人。
- 李文：白家月的朋友。
- 白家月：下个星期要来北京。
- 王一雪：准备去机场接他们。

Read for Meaning：

1. 刘明看到照片，以为照片里的人是杨同乐。
2. 王一雪说明：不是杨同乐，是李文。
3. 两人讨论李文和同乐长得有点儿像，但李文更高、更瘦。
4. 王一雪说下个星期要去机场接家月和李文。
5. 刘明想一起去接他们。

Language Links：

- `以为`：误认照片里的人。
- `像 / 有点儿像 / 长得像`：解释为什么会误认。
- `身高 / 米 / 瘦`：描述李文的外貌。
- `接`：引出本课核心任务。
- `看起来/看上去`：根据照片或外表描述印象。

Class Q&A：

1. 刘明一开始以为照片里的人是谁？
2. 照片里的人其实是谁？
3. 李文和同乐哪里像？哪里不一样？
4. 王一雪为什么要去机场？
5. 如果你是刘明，你会一起去机场吗？为什么？

Micro Output：

学生用 1-2 句话完成：

- 我以为照片里的人是……，其实他是……
- 他看起来……，身高……
- 下个星期，我/王一雪要去机场接……

### 课文二、三、四后续方向

课文二：

- 主题：行李不见、服务台求助。
- 核心输出：描述行李问题并请求帮助。

课文三：

- 主题：机场找人。
- 核心输出：用多项定语描述目标人物。

课文四：

- 主题：到北京第一天的经历复述。
- 核心输出：按时间顺序复述事件。

## 六、练习环节初步调整方向

今天不先重写练习，但先确定方向：

### 1. 保留但需要升级的旧题型

- 选词填空：从单句填空升级为场景短句填空。
- 词句匹配：从词义匹配升级为“语块和功能匹配”。
- 连词成句：保留，用于多项定语和接机句式。
- 课文 Q&A：需要从单题选择升级为分段理解和微输出。

### 2. 建议新增题型

- 情景选句：给机场情景，选择最自然的一句话。
- 信息找人：根据照片或文字线索判断目标人物。
- 句子扩展：从“年轻人”扩展成“穿着黑衣服的短头发的年轻人”。
- 事件排序：用于课文四经历复述。
- 角色回应：给对话上一句，选择/输入下一句。

### 3. 暂不优先的题型

- HSK1 式拼音专项题。
- 单纯汉字书写题。
- 与本课主题无关的机械翻译题。
