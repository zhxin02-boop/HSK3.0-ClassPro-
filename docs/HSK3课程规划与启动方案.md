# HSK3课程规划与启动方案

更新时间：2026-08-17

## 1. 本文目标

本文用于承接 HSK1 阶段已经形成的 Chinese ClassPro+ 教学体系，并规划 HSK3 课程制作的方向、模块结构、题型升级、游戏化设计和数据闭环。

HSK3 不建议从零开始重做，而应在 HSK1 已经跑通的“课前-课中-课后-测试-数据反馈”体系上升级。核心变化是：学生从初级进入初中级衔接阶段，课程应从“识别和简单操练”逐步转向“理解、组织、表达、迁移和反思”。

## 2. HSK1阶段经验总结

### 2.1 已经形成的有效体系

HSK1 已经完成并验证了以下基础链路：

1. 课前预习
   - 生词预习
   - 课文导入
   - quiz 检查
   - 主观题提交
   - 教师端可查看提交情况

2. 课中教师端
   - 生词卡片
   - 词语扩展
   - 语法讲解
   - 课文讲解
   - 看图、填空、匹配、排序等练习
   - 竞赛、排行榜、答题墙
   - 扫码入课和统一课堂控制

3. 课中学生端
   - 接收教师推送题目
   - 实时提交答案
   - 参与课堂练习和测试

4. 课后复习
   - 生词复习
   - 汉字复习
   - 课文复习
   - 作业与复习资源

5. mock test
   - Word/PDF 试卷
   - 听力音频
   - 学生端答题
   - 教师端统计
   - 成绩单
   - 初步防作弊机制

### 2.2 HSK1暴露出的主要问题

1. 课前预习完成度没有预期高

   可能原因是课前部分相对固定：生词、quiz、课文导入、主观题。学生容易把它理解为普通作业，而不是一个有趣的学习入口。

2. 课前内容和课中推进的节奏还可以更细

   HSK1 每课通常用两次课完成，预习可以整体给出。但 HSK3 每课计划用六课时，也就是三次课完成，因此课前内容应该拆成三个阶段，分别对应不同课文或不同教学重点。

3. 部分练习题型适合 HSK1，但不适合继续作为 HSK3 主体题型

   例如看图猜词、译文选句、简单句子转换等，更适合基础识别阶段。HSK3 应逐步增加更高阶的理解、表达和迁移任务。

## 3. HSK3与HSK1的核心差异

### 3.1 学习目标差异

HSK1 目标：
- 认识基础词语
- 理解简单句
- 能进行最基础的问答
- 建立汉字和拼音对应意识

HSK3 目标：
- 理解更长句子和短段落
- 掌握更多语法结构
- 能在具体情景中表达观点和需求
- 能进行较完整的口头和书面表达
- 能根据上下文推断信息
- 能逐渐形成自我复习和自我诊断能力

### 3.2 教学重心变化

HSK1 以“输入和识别”为主。

HSK3 应转向：
- 语法结构理解
- 语篇理解
- 情景表达
- 段落阅读
- 复述训练
- 写作表达
- 错题反思

## 4. HSK3每课整体结构

每课建议按三次课完成，每次课对应一个课前任务包、一个课中重点和一个课后输出任务。

### 4.1 三次课节奏

| 阶段 | 课前 | 课中 | 课后 |
|---|---|---|---|
| 第一次课 | 针对课文一的兴趣导入和轻量预习 | 课文一、生词、核心语法点一 | 词汇复习、短句表达、错题回看 |
| 第二次课 | 针对课文二、三的情景导入 | 课文二、三、语法点二、情景练习 | 短文阅读、口头复述准备 |
| 第三次课 | 针对课文四的任务导入 | 课文四、综合表达、段落理解 | 写作表达、学习报告、错题回收 |

### 4.2 每课固定模块

1. 课前激发
2. 课中讲授
3. 课中练习池
4. 课堂竞赛与游戏化调剂
5. 课后复习与表达
6. 学习报告与错题回收

## 5. 课前部分：从“预习作业”改为“兴趣导入”

### 5.1 设计原则

HSK3 的课前部分不应只是固定的生词和 quiz，而应承担“激发兴趣、降低负担、提前进入情景”的作用。

课前任务应满足：
- 轻量，不让学生感觉负担太重
- 有趣，有明确情景或挑战
- 与当天课文内容直接相关
- 完成后能在课中被使用
- 能形成积分或通关反馈

### 5.2 三段式课前任务

每课拆成三套课前任务：

1. Pre-task A：对应第一次课，主要服务课文一
2. Pre-task B：对应第二次课，主要服务课文二、三
3. Pre-task C：对应第三次课，主要服务课文四和综合表达

每套课前任务不需要完全一样，可以根据内容变化。

### 5.3 课前游戏化设想：故事挑战式预习

课前可以设计为“故事挑战式预习”，把预习包装成角色扮演、故事带入或解救任务。学生不是简单完成一组题，而是在一个和课文主题相关的情境中通关。

基本逻辑：
- 开头给出一个任务：救援、寻找、解决问题、完成委托、帮助某个人。
- 中间通过词语、语法和情景判断逐步推进故事。
- 学生掌握关键词语和关键句式，才能继续通关。
- 最后用一个小表达任务完成故事目标。
- 系统给出积分、称号、徽章或能力展示，并进入班级 PK 和学习报告。

五个核心环节：

1. 情景入口
   - 学生先看到一张图、一段短视频式插画或一个问题。
   - 例如：今天你要帮一个朋友解决问题，他迟到了、迷路了、买错东西了。
   - 入口必须和本课课文主题直接相关，不能只是装饰性的故事。

2. 词语解锁
   - 学生完成少量词语理解任务，解锁后续关卡。
   - 不强调记忆全部生词，而是先掌握完成任务所需的关键词。
   - 关键词要为后面的情景表达服务。

3. 语法线索
   - 用一个非常短的任务引出语法结构。
   - 例如：选择哪句话更自然，或者拖动词语组成一个句子。
   - 语法不是单独讲规则，而是作为完成任务的工具出现。

4. 情景挑战
   - 学生用所学内容完成一个小选择、小判断或一句话表达。
   - 情景挑战要让学生说出或写出后面课中会用到的句子。

5. 积分反馈
   - 根据完成情况获得星星、徽章或积分。
   - 积分可以带入班级 PK 或个人学习报告。
   - 奖励可以多样化，例如“沟通达人”“语法侦探”“任务队长”“表达之星”。
   - 不同学生可以获得不同能力标签，让反馈不只是分数。

课前游戏化的关键不是“加一个游戏壳”，而是让故事、词语、语法和表达任务彼此衔接。学生应该感觉自己是在完成一个任务，同时不知不觉提前进入课文情境。

### 5.4 课前任务例子

主题：去机场接朋友

课前任务 A：
- 看图判断：他在哪里？
- 选择关键词：机场、时间、到、等
- 小挑战：朋友几点到？请选择正确的信息。

课前任务 B：
- 情景选择：朋友找不到路，你怎么说？
- 句型提示：先……然后……
- 小挑战：把三个动作排成正确顺序。

课前任务 C：
- 表达准备：请用三句话说明你怎么去机场。
- 课堂衔接：第二天课上用这三句话进行口头表达。

## 6. 课中讲授部分

### 6.1 保留HSK1中有效的讲授结构

HSK3 课中讲授仍保留：
- 生词卡片
- 生词搭配扩展
- 语法讲解
- 课文分段讲解
- 英文翻译
- 课文问答
- 课文转述

### 6.2 生词讲解升级

HSK1 生词扩展主要是两个短语和一个句子。

HSK3 建议升级为：

1. 核心义
2. 常用搭配
3. 3-5 个情景例句
4. 易错提醒
5. 语义联想或主题联想

其中，学生端重点展示前三项：核心义、常用搭配、3-5 个例句。易错提醒主要作为教师讲解参考，可以放在教师端；语义联想可根据词语价值选择性展示，不必每个词都强行加入。

例子：

词语：影响

- 核心义：to influence; effect
- 搭配：
  - 影响学习
  - 影响身体
  - 有很大影响
- 例句：
  - 晚上睡得太晚会影响第二天的学习。
  - 这件事对他的心情有很大影响。
  - 天气不好，不会影响我们的计划。
  - 父母的话常常会影响孩子。
- 易错提醒：
  - “影响”后面常接名词或动词短语，不能随便和所有词搭配。
- 联想：
  - 原因 -> 影响 -> 结果

### 6.3 语法讲解升级

HSK3 语法讲解应比 HSK1 更生动，避免只给公式。

每个语法点建议包含：

1. 使用场景
2. 结构公式，如果该语法点适合公式化呈现
3. 3-5 个梯度例句
4. 必要的使用提醒

不建议在语法讲解页放太多图示、错误题型或小练习。图示只有在确实能帮助理解时使用；错误辨析和小练习可以放到后面的课中练习池中完成。

例子：

语法点：虽然……但是……

- 场景：表达转折
- 结构：虽然 A，但是 B
- 例句：
  - 虽然今天很冷，但是我还想出去走走。
  - 虽然这件衣服很好看，但是有点儿贵。
  - 虽然他学习很忙，但是每天都运动。
- 错误提醒：
  - 不能只说“虽然今天很冷”，后面需要有结果或转折。

### 6.4 课文讲解升级

课文部分保留英文翻译，但增加篇章理解。

每段课文建议包含：
- 原文
- 英文翻译
- 关键词
- 判断或选择题
- 转述提示
- 简单逻辑图

例子：

课文后问题不只问：
- 他去哪儿？

而应增加：
- 他为什么去那里？
- 他先做了什么，后来做了什么？
- 这段话主要说明什么？
- 如果你是他，你会怎么做？

课文理解的顺序建议为：

1. 先做判断或选择，帮助学生确认基本信息。
2. 再做转述，训练学生把课文内容用自己的话说出来。
3. 必要时提供简单逻辑图，例如“原因 -> 做法 -> 结果”。
4. 最后再进入更开放的理解或表达问题。

### 6.5 汉字模块调整

HSK3 阶段可以去掉 HSK1 中以书写展示为主的汉字练习，因为学生已经具备基本书写能力。

可以替换为：
- 词汇思维导图
- 词族联想
- 主题词网
- 语法目录
- 学习资源索引

例子：

主题：旅行

- 地点：机场、车站、宾馆
- 动作：出发、到达、换车、预订
- 问题：迟到、找不到、太贵、没时间
- 表达：我想…… / 能不能…… / 如果……就……

## 7. 课中练习池设计

### 7.0 命题总原则：循环复现已学内容

课中讲授部分可以主要围绕本课课文、生词和语法展开，但课中练习不能只考本课新内容。HSK3 练习池必须持续循环复现已经学过的词汇、语法和课文表达。

原因：
- 学生如果只围绕单课生词做题，会形成短期记忆，难以迁移。
- HSK3 需要从初级过渡到中级，复现和整合比单课识别更重要。
- 练习应帮助学生把旧词、旧语法和新情境重新连接起来。

命题要求：
- 每组练习至少包含一部分旧词或旧语法。
- 新词、新语法要和旧内容自然组合。
- 不直接大量复用课文原句，但可以改写课文情境。
- 干扰项要来自已学范围，避免超纲。
- 题目要有难度梯度：识别 -> 理解 -> 搭配 -> 语境判断 -> 表达迁移。

例子：

本课新词：影响、决定、参加

可循环旧词：
- 时间类：昨天、明天、小时、分钟
- 地点类：学校、医院、机场、饭店
- 动作类：学习、工作、买、去、回来

练习句：
- 昨天晚上睡得太晚，今天上课有点儿受影响。
- 你决定明天几点去学校？
- 这个活动很多同学都想参加。
- 如果你没有时间，可以下次再来。

### 7.1 去掉或弱化的题型

HSK3 阶段建议去掉或弱化：

1. 看图猜词
   - 适合 HSK1，HSK3 词汇和抽象表达增多，继续作为主力题型意义不大。

2. 简单句子转换
   - 如果只是选择同义句，难度偏低。
   - 可以改造成语法改写或表达升级任务。

3. 译文选句
   - HSK3 不应过度依赖英俄翻译选择。
   - 可以转为情景表达或语义匹配。

4. 单句四选一的低阶填空
   - 可以保留少量，但不作为核心题型。

### 7.2 保留并升级的题型

#### 7.2.1 选词填空升级

HSK1 形式：
- 一个句子对应四个词。

HSK3 形式：
- 一组词对应 5-6 个句子。
- 干扰项更接近。
- 句子长度增加。
- 关注搭配、语境和语法。

例子：

词库：影响、需要、完成、决定、参加、担心

1. 明天的考试很重要，我有点儿____。
2. 如果你想____这个活动，请先告诉老师。
3. 天气不好可能会____我们的旅行计划。
4. 我还没有____今天的作业。
5. 你____什么帮助，可以告诉我。

#### 7.2.2 词句匹配升级

HSK1 形式：
- 词语或问句与简单句匹配。

HSK3 形式：
- 一组 5 个或 8 个项目进行匹配。
- 可以是问答匹配，也可以是情景反应匹配。
- 干扰项要有一定相似度。
- 不能全部是课文原句。

例子：

左侧：
1. 你为什么没来上课？
2. 这件衣服你觉得怎么样？
3. 明天的活动几点开始？
4. 你最近为什么这么忙？
5. 我们怎么去机场？

右侧：
A. 因为我每天都要准备考试。
B. 坐地铁比较方便，也不贵。
C. 我觉得颜色很好看，就是有点儿小。
D. 九点开始，最好八点半到。
E. 对不起，我昨天身体不太舒服。

#### 7.2.3 连词成句保留

连词成句继续保留，因为它能训练语言结构。

HSK3 要求：
- 句子长度增加
- 包含时间、地点、方式、原因等成分
- 可以出现关联词
- 干扰难度提高

例子：

词块：
虽然 / 今天 / 很忙 / 但是 / 我 / 还是 / 想 / 去运动

答案：
虽然今天很忙，但是我还是想去运动。

### 7.3 新增题型

#### 7.3.1 看图表达

HSK3 的看图表达不再只问“他是谁”“他在哪儿”。

应更开放：
- 你觉得发生了什么？
- 他们可能在说什么？
- 这个人为什么这样做？
- 如果你是他，你会怎么办？

要求：
- 不出现超纲词
- 图片要和问题一致
- 问题有开放度，但不能超出学生表达能力

#### 7.3.2 情景表达

情景表达与口语课高度相关，可以嵌入每课主题。

例子：

情景：你约朋友明天下午去看电影，但是你突然有事。

任务：
- 请给朋友发一条微信。
- 内容包括：道歉、说明原因、重新约时间。

学生可用句型：
- 对不起，……
- 因为……所以……
- 我们可以……吗？

#### 7.3.3 段落理解

段落理解是 HSK3 的重点。

形式：
- 80-150 字短文
- 3-5 道理解题
- 题目包括细节、原因、顺序、主旨、推断

例子：

短文：
昨天晚上小王本来想复习汉语，但是他的朋友突然来找他。朋友下个星期要去中国旅行，想请小王帮他练习一些常用句子。小王虽然很忙，但是还是帮朋友练习了一个小时。后来他觉得，教别人说汉语也能帮助自己复习。

问题：
1. 小王昨天晚上本来想做什么？
2. 朋友为什么来找小王？
3. 小王帮朋友练习了多长时间？
4. 小王最后有什么想法？

#### 7.3.4 书面表达

HSK3 写作训练应逐步进入核心位置。

可以从短句写作开始：
- 根据图片写 2-3 句话
- 根据关键词写一段话
- 根据情景写微信
- 根据问题写个人经历

例子：

请用以下词语写一段 40-60 字的话：
昨天、因为、所以、虽然、但是

### 7.4 练习池与每日变化

HSK3 不必每次课都使用完全相同的练习题型。

建议建立“练习池”：
- 每课配置多个题型
- 每次课选择其中一部分
- 教师可以根据课堂状态切换
- 竞赛题从练习池中抽取

这样可以避免课堂形式固定化，也能通过游戏和 PK 调节节奏。

## 8. 课堂竞赛与游戏化设计

### 8.1 游戏化目标

游戏化不是单纯加分或动画，而是让学生觉得：
- 预习有用
- 会用就能通关
- 课堂参与会带来可见反馈
- 班级内部可以形成适度 PK

### 8.2 可设计的机制

1. 课前闯关积分
   - 完成课前任务获得基础分。
   - 完成表达挑战获得额外分。

2. 课堂 PK
   - 小组对战
   - 随机点名
   - 抢答
   - 合作通关

3. 任务徽章
   - 词汇达人
   - 语法侦探
   - 表达之星
   - 阅读高手

4. 复习回收奖励
   - 学生纠正自己的错题，可以获得“修复分”。
   - 鼓励学生看见自己的进步，而不是只看最终成绩。

### 8.3 游戏活动例子

游戏活动可以逐步扩展，不需要一次性固定。原则是：游戏必须服务语言目标，不能只为了热闹。

活动：语法侦探

目标：
- 找出句子中不自然的地方，并改正。

例子：
- 错句：虽然今天下雨，所以我没出去。
- 正确：因为今天下雨，所以我没出去。
- 或：虽然今天下雨，但是我还是出去了。

活动：情景通关

目标：
- 学生根据场景选择合适表达。

场景：
你在饭店点菜，但是服务员听不懂你说什么。

任务：
- 选择最合适的话
- 再自己说一句

## 9. 课后部分与数据闭环

### 9.1 保留内容

课后继续保留：
- 生词复习
- 语法复习
- 课文复述
- 短文阅读
- 作业提交

### 9.2 增加内容

1. 写作表达任务

   每课至少有一个小型写作任务。写作内容可以在下一次课前被带回课堂，用于表达训练。

2. 错题回顾

   学生可以看到：
   - 哪些题错了
   - 正确答案是什么
   - 错误原因可能是什么
   - 推荐复习哪个语法点或词汇组

3. 每课学习报告

   学习报告应帮助学生建立自我认知。

   报告内容包括：
   - 本课完成情况
   - 词汇掌握情况
   - 语法掌握情况
   - 阅读理解表现
   - 表达任务完成情况
   - 错题列表
   - 建议复习内容

### 9.3 数据反馈的教学目标

数据反馈不只是给教师看，也要让学生看到自己：
- 哪些地方掌握不错
- 哪些地方还需要练习
- 自己相比上一课是否有进步
- 下一步应该练什么

原则：
- 给学生信心
- 让学生意识到问题
- 给出可操作的复习建议

## 10. HSK3资源目录设想

- 结构
- 使用场景
- 例句
- 错误提醒
- 对应课程

例子：

## 14. 当前决策摘要

已初步确定：

- HSK3 沿用 HSK1 的完整教学闭环，但内容和题型升级。
- 课前从固定预习改为故事挑战式兴趣导入，用角色扮演或任务通关串联词语、语法和表达。
- 每课按三次课拆成三个课前任务包。
- 课中保留生词、语法、课文、问答、转述。
- 生词讲解以核心义、常用搭配和 3-5 个情景例句为主，易错提醒主要作为教师参考。
- 语法讲解先给场景，再给结构和 3-5 个例句；错误辨析和小练习放到课中练习池。
- 课文理解先做判断或选择，再做转述，可用简单逻辑图辅助篇章理解。
- 汉字书写模块可去掉，改为词汇思维导图和语法目录。
- 课中练习必须循环复现已学词汇、语法和课文表达，不能只围绕本课新词命题。
- 课中练习去掉或弱化看图猜词、译文选句、简单句子转换。
- 选词填空、词句匹配、连词成句要升级。
- 新增看图表达、情景表达、段落理解、书面表达。
- 竞赛和游戏化作为课堂调剂和积分机制。
- 课后增加写作任务、错题回顾和学习报告。
- 先做 HSK3-L01 样板课，再形成可批量制作的规范。
