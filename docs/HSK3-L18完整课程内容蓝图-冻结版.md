## 5. 四个语法点的渐进式设计

每点使用 `presentationMode: progressive_grammar`，完整实现观察例句、结构归纳、课堂表达和图片跟进。`grammar.examples`与`grammarTeachingNotes.examples`一致；每条例句提供汉字、拼音、英文和来源标记。

### 5.1 `g18_01` 概数表达法

- 观察情境：看春节假期、学生人数和旧照片时间，发现相邻数字连用时不表示两个答案，而表示大约数量。
- 教材例句：
  1. 春节大概放七八天假。
  2. 教室里来了五六个学生。
  3. 这些照片是三四年前照的吧？
- 教学扩展示例：
  4. 我每天练习二三十分钟。
  5. 桌子上还有六七个饺子。
- 结构归纳：`相邻数字1 + 相邻数字2 + 量词/名词`，如“三四年、五六个人、七八天”。
- 使用提醒：数字必须相邻；“三五天”不是本课目标结构。
- 课堂表达：你每天学多长时间？你们班大概有多少人？你上次旅行去了几天？
- 跟进图片：`photo-text-1-family-dumplings-gala.png`。
- 跟进目标：根据图片用相邻数字说一个大约数量。
- 示例答案：桌子上大概有六七个饺子。

### 5.2 `g18_02` “刚才”和“刚刚”

- 观察情境：比较“刚才的电话”和“我刚刚学会”，先看词在句中的位置，再判断用法。
- 教材例句：
  1. 刚才的电话是我妈妈打来的。
  2. 我刚才看了一遍，不想再看了。
  3. 我刚刚看视频学会了包饺子。
  4. 他刚刚来北京两个月。
- 教学扩展示例：
  5. 刚才谁来过？
  6. 我刚刚完成今天的练习。
- 结构归纳：`刚才 + 的 + 名词`／`主语 + 刚才 + 动词`；`主语 + 刚刚 + 动词`。
- 使用提醒：“刚才”是时间词，可放句首；“刚刚”是副词，通常放在主语后、动词前。
- 课堂表达：你刚才做了什么？你最近刚刚学会了什么？
- 跟进图片：`photo-text-2-learning-dumplings-video.png`。
- 跟进目标：分别用“刚才”和“刚刚”说两句话。
- 示例答案：我刚才看了一个视频。我刚刚学会包饺子。

### 5.3 `g18_03` 条件复句“只要……，就……”

- 观察情境：看视频联系、朋友决定和健康习惯，找出足够条件与结果。
- 教材例句：
  1. 他刚离开家时，我很不习惯，只要几天不跟他视频，就很想他。
  2. 只要你同意，我们就这么决定了。
  3. 只要坚持每天早睡，身体就一定会好起来。
- 教学扩展示例：
  4. 只要有时间，我就跟家人视频。
  5. 只要每天练习十分钟，你就会慢慢进步。
- 结构归纳：`只要 + 足够条件，+ 就 + 结果`。
- 结构变体：同一主语可放“只要”前或后；两个分句主语不同时，第二个主语放在“就”前。
- 课堂表达：怎样才能学会一个新技能？什么时候你会给家人打电话？
- 跟进图片：`photo-text-3-mother-video-call.png`。
- 跟进目标：用一个简单条件说明会发生的结果。
- 示例答案：只要每天练习，我就会做得越来越好。

### 5.4 `g18_04` 固定格式“从……起”

- 观察情境：看李文从高中到留学的时间线，找出一个变化开始的时间。
- 教材例句：
  1. 他从那时起就努力学习。
  2. 从那天起，我们就变成了好朋友。
  3. 从那次旅游起，我对中国文化更有兴趣了。
- 教学扩展示例：
  4. 从这个学期起，我要每天读中文。
  5. 从学会包饺子那天起，我更喜欢自己做饭了。
- 结构归纳：`从 + 时间/事情 + 起，+ 主语 + 就/开始 + 变化或行动`。
- 使用提醒：“起”表示开始点，不是“站起来”的意思。
- 课堂表达：你从什么时候起学习中文？你想从什么时候起坚持一个新习惯？
- 跟进图片：`photo-text-4-study-goal-timeline.png`。
- 跟进目标：用“从……起”说出目标开始的时间。
- 示例答案：从这个学期起，我要坚持每天读十分钟中文。

### 8.1 问答匹配三组主题

- 第1组：第一次在中国过年的感受、李文开心的原因、春节活动、假期时长和晚睡原因。
- 第2组：没见过却知道对方的原因、带礼物的原因、让客人自己选择饮料、参加包饺子和学习方法。

### 8.2 阅读主题

1. 《第一次在朋友家过节》：礼貌问候、家庭活动和大约时间。

3. 《三四年前的合影》：地点、人物和照片故事。
4. 《只要每天做一点》：通过小行动坚持目标。
5. 《从这个学期起》：学生制定可完成的学习计划。

独立阅读5题：

1. 《不同的节日活动》：4—6句介绍两个家庭过节方式；问“这个家庭会一起做什么？”
2. 《第一次做客》：带小礼物、问好、自己拿水；问“主人为什么说不用客气？”
3. 《我学会骑自行车》：刚开始害怕，后来每天练习；问“他怎样学会的？”
4. 《一张机场照片》：照片时间、地点和离家学习；问“照片为什么重要？”
5. 《我的小目标》：从本月起每天读中文；问“他准备怎样坚持？”

## 12. Homework A/B/C

三次作业均提供Support、Core、Challenge；弱点和错题默认折叠。

### Homework A：My Festival Family Card

- 材料：一张家庭节日照片、自己画的图或隐私安全的节日图片；没有图片也可用文字卡。
- 必答：什么节日？什么时候？你和家人会一起做什么？
- 必用词：至少3个T1词汇。
- 必用结构：Core使用一个概数；Challenge补充“一边……一边……”。
- 发言时间：30—45秒。
- 小组规则：两人互听，每人必须说出“节日＋家庭活动”。
- Support：节日词库、活动词库和完整句框。
- Core：3—4句介绍节日、时间和活动。
- Challenge：比较自己家和另一个家庭的过节方法。
- 产物ID：`post_l18_a_festival_family_card`，`carryTo:B,C`。

### Homework B：My New Skill Card

- 材料：Homework A卡；从A卡选择一个家庭活动作为想学或已经学会的技能，也可选择另一个真实技能。
- 必答：你学会了什么？什么时候学会？谁或什么帮助了你？
- 必用词：至少3个T2词汇。
- 必用结构：Core使用“刚刚”或“刚才”；Challenge正确使用两者各一次。
- 发言时间：30—45秒。
- 小组规则：A介绍技能，B问“你怎么学会的？”，再交换。
- Support：技能词库和“我刚刚……学会……”句框。
- Core：3—4句介绍技能和方法。
- Challenge：说明学会前后有什么变化。
- 产物ID：`post_l18_b_new_skill_card`，`carryFrom:A`，`carryTo:C`。

### Homework C：My Growth Album

- 材料：Homework A卡、Homework B卡、一张旧照片或自画的记忆卡、一张目标计划卡。
- 必答：介绍一个节日家庭活动；介绍一件新学会的事；说明一张照片的时间和故事；介绍一个目标、开始时间和坚持方法。
- 必用词：Support至少5个、Core至少8个L18词汇。
- 必用结构：Core使用“只要……就……”和“从……起”；Challenge再加入概数或“刚才/刚刚”。
- 发言时间：1—2分钟，主要在课堂展示，不上传音频。
- 小组规则：小组可互相提问和检查，但每名学生必须完成有意义的个人发言。
- Support：四步顺序卡“节日→新技能→旧照片→目标”和完整句框。
- Core：实际复用A的节日材料和B的新技能材料，补充照片与目标。
- Challenge：说明一个过去的变化怎样帮助未来目标。
- 产物ID：`post_l18_c_growth_album`，`carryFrom:A,B`。

英文课堂说明必须写清材料、问题、必用词/结构、发言时间、小组规则及“No audio upload is required”。
