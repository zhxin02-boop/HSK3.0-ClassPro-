# HSK3 界面模板与执行标准

> 适用范围：HSK3 课程的 ClassReady+ 课前预习、ClassPro+ 教师端课中讲授与练习界面。  
> 当前样板：`HSK3-L01 我们去机场接你们`。后续 HSK3 课程默认沿用本模板，除非有明确教学原因，不再每课重新设计界面结构。

## 一、总体原则

1. HSK3 不沿用 HSK1 的“拼音训练优先”界面逻辑，界面重点从字词识别转向任务情境、语块、句子和课堂互动。
2. 课前预习要有故事线和任务角色，但不剧透课文细节。
3. 教师端课中讲授要服务教师现场发挥，默认不把所有讲解堆到学生主屏。
4. 学生端提示语言优先使用英文；当课目标内容，如生词、短语、句子，保留中文、拼音和英文释义。
5. HSK3 页面改动应通过 HSK3 专用覆盖层实现，不影响 HSK1 已稳定的拼音、汉字练习和模拟测试逻辑。

## 二、课前预习学生端模板

### 1. 定位

课前预习不是提前学习课文，而是围绕本课主题做“任务预热”。

HSK3-L01 样板任务：

- 角色：You are a student volunteer at the airport.
- 任务：Pick up a new friend at the airport.
- 主线：看照片、判断外貌线索、练习关键语块、规划怎么找到并问候朋友。

### 2. 页面语言规则

- 所有任务说明、提示语、按钮说明、反馈语优先用英文。
- 当课学习内容保留中文，例如：`像`、`身高`、`接朋友`、`欢迎来北京！`
- 中文词句卡必须配：
  - 汉字
  - 拼音
  - 英文释义
  - 例句
  - 例句英文翻译
- 词卡展开后不重复显示拼音和英文释义，只保留一组清晰字段。

### 3. 故事与图片规则

- 每课至少有一张主题背景图，HSK3-L01 使用机场到达大厅。
- 任务角色或目标人物必须有照片支持。
- 对比、寻找、判断类任务可以使用相似人物图，帮助学生理解“像 / 不像 / 有点儿像”等表达。
- 人物图不能裁掉头部；任务照优先保留人物完整上半身或全身，避免底部大面积空白。

### 4. 关卡结构

每个关卡必须是“完成任务的一步”，而不是孤立练习。

推荐结构：

1. Mission Brief：说明角色和任务。
2. Check the Clues：观察照片和外貌线索。
3. Confirm the Mission：确认地点、目的和核心动词。
4. Find Him in the Crowd：选择寻找顺序或策略。
5. Say Hello：选择可用中文句子。
6. Mission Output：生成简单中文行动计划。

### 5. 禁止项

- 不提前出现完整课文。
- 不以课文问答作为课前预习主任务。
- 不把任务说明写成大段中文。
- 不把生词孤立堆成词表。

## 三、教师端课中顶部模板

### 1. HSK3 讲授页顶部一行结构

讲授页顶部固定为一行三组：

| 区域 | 内容 | 规则 |
|---|---|---|
| 左侧品牌区 | `Chinese ClassPro+` + 当前课标签 | 当前课标签移动到品牌下方，不与中间按钮抢空间 |
| 中间互动区 | `词汇 / Vocabulary`、`语法 / Grammar`、`课文 / Text` | 三个按钮并排居中，风格统一，当前模块高亮 |
| 右侧工具区 | `教师主页 / Home`、`隐藏拼音`、`数据面板`、随机点名、计时器 | 功能类按钮风格统一，文字尽量一行显示 |

### 2. HSK3 顶部模块取舍

- HSK3 讲授页不显示 `拼音 / Pinyin` 主模块。拼音模块只属于 HSK1。
- `扫码入课` 在 HSK3 讲授页顶部隐藏，避免占用空间。
- `隐藏拼音` 保留，它是显示控制工具，不是拼音教学模块。
- `教师主页`、`数据面板` 保留，便于课堂中快速返回或看数据。

### 3. 实现标准

- HSK3 专用逻辑只在 `LESSON_DATA.meta.level === 'HSK3'` 时启用。
- 非 HSK3 课程不得被 HSK3 顶部覆盖影响。
- 非讲授模式必须回落到原有 `_snav()`，确保练习题型导航可见。
- HSK3 页面可通过 `body.hsk3-teach-mode`、`body.hsk3-practice-mode` 做模式级样式控制。

## 四、教师端词汇讲授模板

### 1. 词汇总览

- 不显示分类筛选，如“动作 / 其他 / 物品”等。HSK3-L01 词汇分类价值不高，容易造成视觉噪音。
- 词卡只显示：
  - 汉字
  - 拼音
  - 英文释义
- 总览词卡不显示小田字格。
- 词卡内容垂直居中，避免下方大面积留白。
- 点击词卡进入讲解详情。

### 2. 词汇详情

点开词后固定显示：

1. 大字
2. 拼音
3. 英文释义
4. 场景配图
5. 短语
6. 例句

重点是短语和例句。大字和英文只是快速定位，不作为主要讲解内容。

### 3. 不显示内容

- 不显示汉字书写区。
- 不显示朗读按钮区。
- 不显示词性作为主要信息。
- 不显示 HSK1 式田字格练习。

### 4. 配图规则

词汇详情下方空白区域优先放场景图。

HSK3-L01 可按词义匹配：

- 外貌类：人物照片，如 `像`、`身高`、`瘦`、`短`、`头发`、`年轻`
- 机场行动类：机场或目标人物图，如 `接`、`站`、`中间`、`照片`
- 行李问题类：机场背景或行李场景，如 `行李`、`丢`、`箱子`、`护照`、`服务台`

后续课程应补充更精准的词汇配图，不要长期依赖同一张通用背景图。

## 五、教师端语法讲授模板

HSK3 语法讲授遵守“场景先行，而不是先抛公式”。

固定顺序：

1. 场景：一张图、一个微情景或两句对话，让学生先理解说话目的。
2. 发现：突出目标结构，引导学生观察共同部分。
3. 结构：必要时给出公式或语序框架，保持简短。
4. 例句：3-5 个递进例句，至少 1 个复现旧内容，至少 1 个真实情景句。
5. 教师提示：使用条件和常见错误，默认教师可见，不占学生主屏。

执行要求：

- 不把语法页做成表格说明。
- 不先给抽象公式再给例句。
- 例句要服务情景表达，不能只为了展示结构。

## 六、教师端课文模块模板

课文模块用于课堂讲解，不属于课前预习。

基本要求：

- 课文显示应保留教师可切换视图。
- 课文 Q&A 必须有题目，不能空白。
- Q&A 不应直接泄露答案。
- 可根据课堂需要显示中文、拼音、英文，但默认避免信息过载。

后续待细化：

- HSK3 课文讲解页是否采用“场景图 + 人物关系 + 分段理解”的新结构。
- 是否为每篇课文增加教师提示和可投屏问题。

## 七、教师端练习导航模板

练习模式必须保留题型导航，不得被 HSK3 讲授导航覆盖。

HSK3-L01 当前练习导航包括：

- 图片猜词 / Picture
- 选词填空 / Fill
- 词句匹配 / Word Match
- 词了个词 / Matching Game
- 汉字区辨 / Characters
- 句子转换 / Sentence
- 连词成句 / Ordering

布局要求：

- 题型按钮位于顶部题型列表区域。
- 当前题目面板应与题型列表左边缘大致对齐。
- 题目区域不宜过窄，不要贴左侧栏；需要给教师投屏留出稳定阅读区域。
- 练习题型结构后续可继续改，但导航入口必须始终可见。

## 八、代码执行标准

### 1. HSK3 覆盖层

新增 HSK3 专用行为时，使用如下判断：

```js
if (!window.LESSON_DATA || !LESSON_DATA.meta || LESSON_DATA.meta.level !== 'HSK3') return;
```

### 2. 导航覆盖

HSK3 讲授页可以覆盖 `_snav()`，但必须保存原函数：

```js
var hsk3BaseSnav = ap._snav.bind(ap);
ap._snav = function () {
  if (this.mt !== 'teach') return hsk3BaseSnav();
  // HSK3 teach nav
};
```

这样可以避免练习、竞赛、测试导航被误删。

### 3. 模式样式

渲染后给 body 添加模式类：

```js
document.body.classList.toggle('hsk3-teach-mode', this.mt === 'teach');
document.body.classList.toggle('hsk3-practice-mode', this.mt === 'practice');
```

CSS 只通过这些类控制 HSK3 特定布局，避免全局污染。

### 4. 顶部布局

HSK3 讲授页顶部推荐三列：

```css
body.hsk3-teach-mode .header:has(.hsk3-top-nav) {
  grid-template-columns: 260px 1fr auto;
}
```

若屏幕宽度不足，可在媒体查询中降级为多行，但桌面投屏优先保持一行。

### 5. 验证标准

每次改 HSK3 教师端界面后至少检查：

- 教师端页面返回 `200`。
- HSK3 讲授页顶部不遮挡课程标题和教师主页。
- 词汇、语法、课文三个按钮并排。
- 练习模式题型导航仍可见。
- 词汇总览无田字格、无分类筛选。
- 词汇详情无汉字书写区、无朗读区，并显示短语和例句。

## 九、当前待继续内容调整

界面模板固定后，下一步进入内容层调整：

1. 补齐 HSK3-L01 所有词的短语与例句。
2. 优化词汇配图，不再只使用通用机场或人物图。
3. 重做语法讲解内容，按“场景、发现、结构、例句、教师提示”补齐。
4. 检查课文 Q&A 题目质量。
5. 重新规划练习题型结构和课堂使用顺序。
