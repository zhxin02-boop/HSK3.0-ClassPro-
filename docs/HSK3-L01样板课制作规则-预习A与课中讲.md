# HSK3-L01 样板课制作规则：预习 A 与课中讲

> 当前样板：`HSK3-L01 我们去机场接你们`  
> 已确认范围：课前预习 A 段 + 课中 `讲 / Teach` 环节  
> 用途：作为后续制作 HSK3 其他课次、L01 B/C 段和新增数据内容时的执行标准。

## 1. 总体定位

HSK3 不再按 HSK1 的“拼音、认字、简单选择题”作为主线。HSK3 的核心是：

- 用任务情景带动输入。
- 用图片和人物关系降低理解负担。
- 用词语、语块、句子支撑真实表达。
- 课前不剧透课文，课中再揭示课文内容。
- 教师端讲授页帮助教师组织课堂，而不是把所有说明文字堆给学生。

当前 L01 样板已确认的制作顺序是：

1. 先完成课前预习 A 段：围绕课文一主题做任务预热。
2. 再完成课中讲授：词汇、语法、课文三块。
3. 确认样板结构后，再进入课中 `练 / Practice` 的题型升级。

## 2. 课前预习 A 段规则

### 2.1 定位

课前预习 A 段不是提前讲课文，而是让学生进入主题任务。

HSK3-L01 A 段任务：

- Role: You are a student volunteer at the airport.
- Mission: Pick up a new friend at the airport.
- Story line: look at a photo, check appearance clues, think how to find the person, choose what to say.

学生完成后应该获得“进入课堂的准备”，而不是提前知道课文情节、人物误会和答案。

### 2.2 语言规则

- 所有提示性语言、任务描述、反馈语优先使用英文。
- 当课目标内容保留中文，例如生词、短语、目标句。
- 中文词卡必须提供：拼音、英文释义、中文例句、英文翻译。
- 词卡展开后不要重复显示同一组拼音和释义。
- 中文不应大面积出现在任务说明里，否则会增加学生认知负荷。

### 2.3 故事关卡规则

每一关都必须是任务推进的一步，不是孤立练习。

L01 A 段当前固定结构：

1. Mission Brief：说明角色和任务。
2. Check the Clues：看目标人物照片，观察外貌。
3. Confirm the Mission：确认地点、动作和目标。
4. Find Him in the Crowd：判断找人的策略和顺序。
5. Say Hello：选择见面时能说的中文句子。
6. Mission Output：生成简单中文行动计划。

### 2.4 图片规则

- 必须有沉浸式背景图，L01 A 段使用机场到达大厅。
- 目标人物必须有照片支持。
- 相似人物对比任务必须有两张人物图，帮助理解 `像 / 有点儿像 / 不像`。
- 截图或裁图时必须保留关键部分，尤其是人物头部、脸部、上半身和任务相关物体。
- 不能只考虑图片尺寸，也要考虑呈现效果：如果裁切后头部、表情、手中行李等关键信息缺失，宁可调整容器比例，也不要硬裁。
- 避免图片底部或上方出现大面积无意义空白。

### 2.5 禁止项

- 不提前出现完整课文。
- 不提前说明课文中的人物误会和结局。
- 不把预习做成生词表。
- 不用课文 Q&A 作为课前主任务。

## 3. 课中讲授顶部规则

课中 `讲 / Teach` 固定为三个模块：

- 词汇 / Vocabulary
- 语法 / Grammar
- 课文 / Text

顶部布局规则：

- `Chinese ClassPro+` 在左侧。
- 当前课标签放在品牌下方或品牌旁边的稳定位置，不遮挡中间按钮。
- 词汇、语法、课文三个主按钮并排居中，样式统一，当前模块高亮。
- 右侧保留 `教师主页 / Home`、`隐藏/显示拼音`、`数据面板`、随机点名、计时器。
- HSK3 讲授页不显示 `拼音 / Pinyin` 主模块；该模块只属于 HSK1。
- `扫码入课` 在 HSK3 讲授页顶部隐藏，避免占位。

## 4. 词汇讲授规则

### 4.1 词汇总览

总览页只显示：

- 汉字
- 拼音
- 英文释义

不显示：

- 分类筛选
- 小田字格
- 汉字书写区
- 朗读按钮

词卡要垂直居中，卡片尺寸紧凑，避免下方大面积空白。

### 4.2 词汇详情

点开词后固定显示：

1. 大字
2. 拼音
3. 英文释义
4. 短语
5. 例句
6. 必要时显示配图

短语和例句是重点。大字、拼音、释义用于快速定位，不应占据过多空间。

### 4.3 配图判断

不是所有词都必须配图。

适合配图的词：

- 具体人物外貌：`像`、`身高`、`瘦`、`短`、`头发`、`年轻`
- 机场动作和地点：`接`、`站`、`中间`、`机场`
- 物品和问题：`行李`、`箱子`、`护照`、`服务台`

不适合强行配图的词：

- 抽象判断或功能词，如 `以为`、`应该`、`好像`
- 如果没有能直接帮助理解的图，直接展示生词卡、短语和例句即可。

### 4.4 图片呈现

- 图片不能把人物头部裁掉。
- 图片不能只露出身体局部，除非该词明确与该身体局部相关。
- 对于人物照片，优先保留脸、头发、上半身和手中物品。
- 对于词汇详情左侧卡片，汉字和图片之间不能出现过大空白。
- 有图时卡片可以稍高；无图时卡片必须自动收缩。

## 5. 语法讲授规则

### 5.1 总体原则

语法讲授不先抛公式，而是先给场景，再让学生发现结构。

固定结构：

1. Scene：场景图或微情景。
2. Notice：对比发现。
3. Visual Rule：图示规则。
4. Impression / Key Words：关键词或语义标签。
5. Build the Sentence：句子搭建。
6. Try More：递进例句。
7. Teacher Tip：教师提示。

### 5.2 L01 已确认语法样板

#### 看上去 / 看起来

图示逻辑：

- 照片或看到的人
- 第一眼印象
- `人/物 + 看起来/看上去 + 描述`

核心对比：

- `他很高。` = 听起来更像确定事实。
- `他看起来很高。` = 根据看到的外表做判断。

#### 疑问代词的非疑问用法（1）

图示逻辑：

- 行李不见了或记忆不确定的情景。
- 对比“真问题”和“不确定信息”。

核心对比：

- `你在哪儿看到？` = asking for a clear place.
- `我好像在哪儿看到过。` = somewhere, but not sure.

#### 多项定语

图示逻辑：

- 机场找人。
- 从宽泛目标逐步加线索。

示例路径：

- `年轻人`
- `短头发的年轻人`
- `穿着黑衣服的短头发的年轻人`

### 5.3 执行要求

- 尽量把文字说明转成图示、箭头、结构块、对比卡。
- 例句保留，但不能只是普通列表。
- 每个语法点至少有一个课文原句和一个真实情境句。
- 教师提示可以保留，但不应抢占主屏。

## 6. 课文讲授规则

### 6.1 课文讲授定位

课文讲授属于课中揭示，不属于课前预习。

课文页目标：

- 理解场景。
- 理解人物关系。
- 回到课文原貌。
- 通过语言回扣理解关键词。
- 通过 Q&A 和复述完成输出。

### 6.2 页面结构

当前课文讲授固定为：

1. Scene：只保留场景和任务。
2. People：人物关系，必须配头像。
3. Original Text：直接呈现课文原貌。
4. Language Links：在课文中用下划线标记语言点，中文解释中文。
5. Text Q&A：点开问题后显示答案。
6. Retell：用思维导图或支架完成一段复述。

### 6.3 显示按钮

课文讲授只保留：

- 汉字 + 拼音
- English
- 问答 Q&A

不保留：

- 拼音单独视图
- 中英拼音混合视图

### 6.4 Text Q&A

Text Q&A 不使用四选项题，因为太容易，不能有效训练 HSK3 阅读理解。

当前 L01 规则：

- 基于课文内容改写为相关主题小篇章。
- 每个小篇章对应开放式阅读理解问题。
- 答案默认折叠，点击后显示。
- L01 样板为 4 个小篇章：
  1. 照片里的人
  2. 不一样的地方
  3. 下星期的安排
  4. 如果你去接人

## 7. 数据制作规则

### 7.1 课前数据

课前任务写入 `previewMissions`。

每个任务至少包含：

- `roleDescriptionEn`
- `storyIntroEn`
- `visuals.backgroundImage`
- `visuals.friendPhoto`
- `stages`
- 每关的 `screenPromptEn`
- `keywordCards`

### 7.2 词汇数据

词汇讲授依赖：

- `vocabulary`
- `vocabExtensions`

每个重点词建议补：

- `teachingFocus`
- `collocations`
- `examples`
- `teacherTip`

是否配图由词义决定，不强制所有词都有图片。

### 7.3 语法数据

语法图示化依赖：

- `grammar`
- `grammarTeachingNotes`
- `grammarTeachingNotes[id].visualLearning`

`visualLearning` 建议字段：

- `image`
- `sceneTitleEn`
- `scenePromptEn`
- `compare`
- `blocks`
- `impressions`
- `buildSteps`

### 7.4 课文数据

课文讲授依赖：

- `texts`
- `textTeachingNotes`

每篇课文建议补：

- `scene`
- `characters`
- `languageLinks`
- `classQuestions`
- `retellScaffold`
- `teacherTip`

Text Q&A 使用 `inClass.questionGroups.r2_passage_choice`，题型为 `passage_reading`。

## 8. 后续制作检查清单

制作下一段或下一课前，逐项检查：

- [ ] 课前是否有明确角色和任务。
- [ ] 课前是否没有剧透课文情节。
- [ ] 课前提示语是否以英文为主。
- [ ] 关键人物、目标物、场景是否有图。
- [ ] 图片是否保留关键部分，尤其人物头部和脸部。
- [ ] 词汇讲授是否突出短语和例句。
- [ ] 抽象词是否避免强行配图。
- [ ] 语法是否从场景进入，而不是从公式进入。
- [ ] 语法说明是否尽量图示化。
- [ ] 课文页是否保留课文原貌。
- [ ] 课文语言回扣是否在原文中标记。
- [ ] Q&A 是否为小篇章阅读理解，而不是简单四选项。
- [ ] 复述是否有支架，而不是让学生凭空说。
- [ ] HSK3 专用覆盖是否只对 HSK3 生效，不影响 HSK1。
