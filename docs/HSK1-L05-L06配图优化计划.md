# HSK1-L05/L06 生词配图优化计划

> 目标：保持前几课高质量配图风格，同时减少逐词单独生图的时间成本。L05/L06 先服务课堂词卡和图片猜词，后续再补全非核心词。

## 一、优化原则

1. 先做图片猜词目标词和具体名词，不按生词表逐词全量生图。
2. 一张图可以服务多个词，但图片猜词目标必须一眼可辨，不能同时明显指向多个选项。
3. 抽象词、功能词和语法词先用情景图复用或暂不配图，不单独做“概念图”。
4. 同一课使用同一视觉模板：明亮、干净、国际学生友好的教育插画；无文字、无汉字、无拼音、无水印。
5. 路径先占位，图片生成后只替换文件并写回 vocabulary.image，题型通过适配层读取，不在题目里重复维护图片路径。

## 五、批量生图模板

每次批量生成 4 张为一组，保证风格统一：

```text
Create a clear educational illustration for HSK1 beginner Chinese learners.
Target word: "{word}". Meaning: "{meaning}".
The image should communicate the meaning at a glance, with one clear subject, a simple light background, and a friendly classroom-appropriate semi-realistic 3D educational illustration style.
No text, no Chinese characters, no pinyin, no English words, no logos, no watermark.
Avoid complex scenes, crowded people, dark backgrounds, cropped objects, and extra objects that could match another answer choice.
Square composition for a vocabulary flashcard.
```

## 七、验收和写回

生成后每张图只做三步验收：

1. 1 秒内能否猜出目标词。
2. 是否无文字、无商标、无水印。
3. 是否会误导到同课另一个图片猜词答案。

通过后写回：

```json
{
  "hanzi": "手机",
  "image": "images/vocab/hsk1-l06/v01_shouji.png"
}
```

然后运行验证脚本检查 `v1_image_guess` 是否能从 vocabulary.image 自动拿到图片。
