# HSK3-L01 课后反馈修改记录

## 课后作业

- 课后作业不再使用客观题为主的形式，改为输出型闭环。
- 每次课固定三类任务：
  - 5 个词语成段：先写 3 句，后续可拓展到 5 句。
  - 课文叙述体改写：把当课课文改写为第三人称或叙述体表达。
  - 绘本口语准备：给学生一组图序提示，课后准备口语展示。
- 第一次出现叙述体改写时提供样例，后续以支架为主。

## 生词讲解

- HSK3 生词讲解按 A/B/C 三次课归类。
- 教师端保留拼音隐藏，并新增英文隐藏。
- 例句尽量一行展示，不主动换行。
- 当前课次生词优先使用当前课次语言范围，避免 A 课次生词讲解中大量出现 B/C 课次词语。

## 课文配图

- 当前替代图不作为最终方案。
- 后续课文配图优先使用真实照片或真实感横版图片。
- 素材要求：横版比例，关键人物和场景不能被裁切，避免使用生词配图中的重复样例图。
