# HSK3-L01 课中练习环节设计方案

> 当前范围：`HSK3-L01 我们去机场接你们`  
> 前置状态：课前预习 A 段、课中 `讲 / Teach` 已基本确定。  
> 本文目标：确定 `练 / Practice` 的题型结构和第一轮落地顺序。

## 1. 练习环节定位

HSK3 的课中练习不是 HSK1 式“识别词、选意思、拼句子”的简单升级，而是要帮助学生把讲授内容放回场景中使用。

L01 的练习主线应围绕：

- 看照片并描述人物。
- 在机场找到目标人物。
- 说明行李或地点问题。
- 用本课语法组织更长的描述。
- 基于课文信息完成理解、判断和复述。

练习题型要从“知道这个词是什么意思”升级到“能不能在接机任务里用出来”。

## 3. 练习模块建议结构

HSK3-L01 的 `练 / Practice` 建议分成 5 类：

### 3.1 Scene Choice / 情景选句

给一个机场或照片情景，学生选择最自然的中文句子。

目标：

- 训练语块和句子在场景中的使用。
- 避免只考词义。

例：

场景：You see a person in the photo, but you are not sure.  
可选句：

- 他看起来有点儿像我的朋友。
- 我要睡觉。
- 这个菜很好吃。

适合覆盖：

- `看起来/看上去`
- `像/不像/有点儿像`
- `以为`
- `接朋友`

### 3.2 Clue Builder / 线索扩展

从一个简单名词逐步扩展为更具体的描述。

目标：

- 训练多项定语。
- 训练机场找人的核心表达。

例：

`年轻人`  
→ `短头发的年轻人`  
→ `穿着黑衣服的短头发的年轻人`

适合形式：

- 拖拽排序。
- 选择下一条线索。
- 连词成句。

### 3.3 Phrase Function Match / 语块功能匹配

左侧是语块，右侧是使用功能，不再只是英文释义。

例：

| 语块 | 功能 |
|---|---|
| 我还以为是…… | say your first wrong idea |
| 去机场接人 | go to the airport to pick someone up |
| 看起来有点儿像 | describe a visual impression |
| 在哪儿看到过 | say an unclear place in memory |

目标：

- 学生知道什么时候用，而不是只知道怎么翻译。

### 3.4 Info Reading / 信息阅读

给短篇信息或人物卡，让学生判断目标人物、地点、时间或事件。

目标：

- 训练 HSK3 阅读理解。
- 复现课文信息但不机械重复原句。

可继续沿用当前 `r2_passage_choice` 的小篇章阅读形式。

### 3.5 Guided Output / 支架输出

给图片、人物卡或关键词，学生输出一句或一小段。

目标：

- 让学生把词汇、语法、课文信息整合成表达。
- 教师端可用云墙展示，便于课堂讲评。

例：

`我要去机场接一个朋友。他看起来…… 他……`

## 4. L01 第一轮题型落地建议

第一轮不要一次性重做所有练习。建议先做 3 个最能体现 HSK3 特点的样板：

### 第一优先级：情景选句

原因：

- 最能体现“从词义到场景使用”的升级。
- 学生操作简单，教师端容易投屏。
- 可以快速覆盖 A 段核心词和语法。

建议题量：4-6 题。

### 第二优先级：线索扩展

原因：

- 和 L01 第三个语法点“多项定语”高度匹配。
- 很适合机场找人主题。
- 可以复用连词成句或新增更清晰的线索卡片 UI。

建议题量：3-4 题。

### 第三优先级：支架输出

原因：

- HSK3 必须逐步进入表达。
- 可以复用现有 `pictureTalk / open_response` 和云墙框架。
- 能把课前预习和课中讲授串起来。

建议题量：2-3 题。

## 5. 第一轮不建议先做的内容

- 不先重做所有旧题型。
- 不先大规模新增复杂交互。
- 不把练习做成单纯翻译题。
- 不把课文 Q&A 再改回四选项。
- 不优先做汉字书写或拼音专项。

## 7. 教师端 UI 原则

练习页要区别于讲授页：

- 讲授页服务教师讲解。
- 练习页服务学生即时参与。

练习页顶部必须保留题型导航，不能被讲授页的三个按钮覆盖。

题型按钮建议按 HSK3 练习目标重新命名：

- 情景选句 / Scene
- 线索扩展 / Clues
- 语块匹配 / Phrases
- 篇章阅读 / Reading
- 支架输出 / Output

旧按钮是否保留，取决于该题型是否真的服务 HSK3：

- `选词填空` 可保留，但内容必须场景化。
- `连词成句` 可保留，但优先用于多项定语和复杂句。
- `汉字区辨` 暂时不作为 HSK3 主练习入口。

## 8. 学生端作答原则

- 客观题仍可使用统一发题、收题、公布答案流程。
- 主观题使用 `open_response` 和云墙。
- 提示语优先英文。
- 目标中文句子保留汉字和必要拼音。
- 题目难度要让学生需要调用语境，而不是看一个词就能秒选。

## 9. 第一轮实施步骤

建议下一步按以下顺序执行：

1. 新增 `scene_sentence_choice` 数据 4-6 题。
2. 在教师端接入情景选句渲染和发题。
3. 确认学生端收到题后显示合理。
4. 再做 `clue_builder` 样板 2-3 题。
5. 最后调整 `pictureTalk` 为支架输出。

第一轮验收标准：

- 教师端练习导航能看到新题型。
- 情景选句不是简单词义题。
- 至少一题复现课前 A 段任务。
- 至少一题复现课中语法。
- 至少一题能连接到课文一内容。
- 学生端能收到并提交答案。

## 10. HSK3 题型池总览

下面是 HSK3 阶段可以逐步建设的完整题型池。它不是 L01 一次性全部上线的清单，而是后续课程制作时的题型资源库。每一课根据主题、语法和课文类型选择其中一部分。

### 10.1 词汇与语块类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 语块功能匹配 / Phrase Function Match | 识别语块用途，而不是只翻译词义 | 新词、固定搭配、交际语块 | 高 |
| 场景选词 / Contextual Word Choice | 在短语境中选择合适词语 | 容易混淆词、抽象词 | 高 |
| 词语搭配 / Collocation Match | 搭配词和中心词 | 动宾搭配、形容词搭配 | 高 |
| 近义词辨析 / Similar Word Contrast | 区分相近表达 | `像/好像`、`以为/觉得` | 中 |
| 词义推断 / Meaning from Context | 从上下文推断词义 | 阅读课文、短篇章 | 中 |
| 词语归类 / Semantic Sorting | 按意义或功能分类 | 人物外貌、动作、地点 | 低 |

### 10.2 语法与句式类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 情景选句 / Scene Sentence Choice | 在情景中选择自然句子 | 新语法初练 | 高 |
| 句子扩展 / Sentence Expansion | 从短句扩展成更完整表达 | 多项定语、程度补充 | 高 |
| 连词成句 / Sentence Ordering | 组织语序 | 多项定语、连动句、关联词 | 高 |
| 结构替换 / Pattern Substitution | 保持结构，替换信息 | 课堂快速操练 | 中 |
| 句子改写 / Sentence Rewrite | 用目标语法改写句子 | `虽然...但是...`、`一...就...` | 中 |
| 语法对比判断 / Grammar Contrast | 判断两个句子的语义差别 | 事实 vs 印象、问题 vs 不确定 | 中 |
| 错误修正 / Error Correction | 发现并修改常见错误 | 复习和巩固阶段 | 中 |

### 10.3 信息理解与阅读类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 小篇章阅读 / Passage Reading | 阅读短文并回答开放问题 | 课文 Q&A、复现课文主题 | 高 |
| 信息找人 / Find the Person | 根据线索识别人物 | 接机、找人、人物介绍 | 高 |
| 信息匹配 / Information Match | 匹配人物、地点、事件 | 多人物课文 | 高 |
| 判断正误 / True or False | 快速检查关键信息 | 课文理解基础层 | 中 |
| 事件排序 / Event Ordering | 按时间或逻辑排序 | 日记、经历、旅行路线 | 中 |
| 标题匹配 / Title Match | 概括短段主旨 | 阅读进阶 | 中 |
| 信息补全 / Information Gap | 根据材料补缺失信息 | 表格、行程、通知 | 中 |
| 段落排序 / Paragraph Ordering | 组织短篇章结构 | HSK3 后段课程 | 低 |

### 10.4 听力理解类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 听后选图 / Listen and Choose Picture | 根据听力选择图片 | 人物、地点、动作 | 中 |
| 听后选句 / Listen and Choose Sentence | 听懂核心句意 | 语块和句型复现 | 中 |
| 听后判断 / Listening True or False | 判断信息是否正确 | 课文听力复现 | 中 |
| 听后记录关键词 / Listen and Note | 记录名字、时间、地点、数量 | HSK3 进阶听力 | 中 |
| 听后排序 / Listening Event Ordering | 根据听力排序事件 | 经历、路线、安排 | 低 |

### 10.5 口语与互动类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 支架输出 / Guided Output | 用框架说一句或一小段 | 每课核心输出 | 高 |
| 看图表达 / Picture Talk | 看图描述人物、地点、事件 | 机场、餐厅、学校等主题 | 高 |
| 角色回应 / Dialogue Response | 根据上一句做自然回应 | 交际功能练习 | 高 |
| 信息差问答 / Info Gap Q&A | 学生互问互答补全信息 | 人物卡、行程卡 | 中 |
| 任务计划 / Mission Plan | 说出完成任务的步骤 | 接人、找东西、安排活动 | 中 |
| 复述支架 / Retell Scaffold | 根据提示复述课文或经历 | 课文讲完后 | 高 |
| 云墙展示 / Cloud Wall Output | 收集全班主观答案并讲评 | 口语、写作、复述 | 高 |

### 10.6 写作与表达类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 句框填写 / Sentence Frame Writing | 在句框中补全关键信息 | 初步输出 | 高 |
| 一句话描述 / One-Sentence Output | 独立写一句目标表达 | 词汇和语法巩固 | 高 |
| 小段复述 / Short Retell Writing | 用支架写 3-5 句 | 课文复述 | 中 |
| 图片小作文 / Picture-Based Writing | 根据图写短段 | HSK3 中后期 | 中 |
| 信息转写 / Info-to-Text | 把表格/人物卡改写成短文 | 人物介绍、行程安排 | 中 |
| 错句重写 / Rewrite Correctly | 修改后完整重写 | 语法巩固 | 中 |

### 10.7 综合任务类

| 题型 | 目标 | 适用场景 | 优先级 |
|---|---|---|---|
| 任务闯关 / Mission Steps | 多步完成一个真实任务 | 课前和课中综合练习 | 高 |
| 线索推理 / Clue Reasoning | 根据多个线索判断答案 | 找人、找物、安排路线 | 高 |
| 角色卡任务 / Role Card Task | 按角色完成交流 | 课堂小组活动 | 中 |
| 小组竞答 / Team Challenge | 复习并提高课堂参与 | 赛 / Battle | 中 |
| 迷你项目 / Mini Project | 输出一个完整成果 | 单元复习 | 低 |

## 11. 题型池使用原则

1. 每课不需要使用所有题型。每次课选择 3-5 个核心题型即可。
2. 一个题型可以跨课复用，但每次要换场景、人物或任务。
3. HSK3 题型要优先考“能不能在语境里用”，不要只考“知不知道意思”。
4. 旧题型可以保留，但必须升级内容质量。例如选词填空要场景化，连词成句要服务真实表达。
5. 主观输出题必须有支架，不能让学生凭空说或写。
6. 阅读题要逐步从单句理解过渡到小篇章理解。
7. 听力题先不急着全面铺开，等文本和练习池稳定后再集中补。

## 12. L01 推荐落地顺序

结合 L01 当前主题，建议按以下顺序逐步开发：

1. 情景选句 / Scene Sentence Choice
2. 线索扩展 / Clue Builder
3. 语块功能匹配 / Phrase Function Match
4. 支架输出 / Guided Output
5. 信息找人 / Find the Person
6. 事件排序 / Event Ordering
7. 听后选句 / Listening Choice
8. 小段复述 / Retell Scaffold

先完成前 4 个，就可以形成 L01 练习环节的第一版可用闭环。
