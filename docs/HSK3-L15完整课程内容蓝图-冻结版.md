## 1. 教材来源与边界

- 仅从 L15.txt 提取教材事实：24个正式生词、2个专有名词、4个语法点、3篇对话和1篇日记。
- 课文1—3为对话；课文4为连续日记，不得渲染为聊天气泡。
- 教材没有音频、图片或独立练习。音频使用 null / missing，第一阶段显示“原音频待导入”并走阅读路径。
- 教材中文、拼音、英文、生词释义、语法说明、语法例句和课文原文原样保存。
- 语法区“在……看来”的首例写作“在我们中国看人看来”，课文原文为“在我们中国人看来”。两处原文均保留并附编辑说明；课堂观察优先使用课文中的正确句式，不静默改写教材。
- 简明中文释义、教学标题、问题、练习、任务、图片、文化讨论、复述支架和作业均标记 teaching_extension。

## 5. 语法四步

- g15_01 根据：观察依据和行动，归纳“根据＋名词/情况＋行动”，用社区图根据老人和孩子需要提出变化。
- g15_02 数量重叠：观察“一点儿一点儿、一天一天、两个两个”等，归纳“数词＋量词＋数词＋量词＋（地）＋动词”，描述游客怎样分组了解老城。
- g15_03 在……看来：保留教材原始例句并附编辑说明；课堂观察使用课文正确句和其余教材句，比较个人与群体观点。
- g15_04 不一会儿：观察短时间变化，归纳“不一会儿（就）＋新情况”，用河边图讲心情怎样变化。

四个点均使用 progressive_grammar、mergeNoticeObserve、observeMode、observePrompt、5组逐项对应的observeHighlights、visualLearning、oralQuestions、structureVariants和含图片、英文提示、中文目标、示例答案、示例拼音的followUp。

## 6. 课文五阶段

每篇固定：听/读课文 → 3道整体选择 → 5道细节问答 → 展示教材原文 → 语言与应用。

- 课文1：居住评价、家庭需求、行动结果；细节检查环境、位置、孩子活动、购房原因和变化依据。
- 课文2：旅行咨询、人物经验、交流目的；细节检查南京经历、历史、景点、外地人不知道的地方和晚饭安排。
- 课文3：黄河名称、历史意义、文化观点；细节检查颜色、最长河判断、居住历史和“像妈妈”的含义。
- 课文4：最喜欢的地方、时间发展、情绪变化；细节检查位置、景物、季节活动、成年后的做法和“不一会儿”的结果。

整体题只问大意、发展、人物关系或目的；细节题不重复整体题，统一保存ID、中文、拼音、答案、答案拼音、acceptedAnswers和informationPoint。

## 7. 正式练习

- v5_vocab_fill：3组×5题；v7_word_match：3组×5对；g1_ordering：5题。
- scene_sentence_choice：10题；v6_description_guess：10题；v2_say_guess：8题；v3_blind_box：4题。
- g2_picture_complete：8题；r2_passage_choice：5题；r3_independent_reading：5题；r4_paragraph_fill：5题。
- t3_chain_sentence：5题；t2_task_card：4个MINI任务＋1个综合任务；pk_question：3题。
- 词汇情景的8个提示必须对应各自课文图片和信息点，不得使用通用“使用目标词介绍场景”。
- v2_say_guess只显示可完整容纳的短词卡；v7_word_match使用完整问题与完整回答；r3_independent_reading每题必须显示标题、短文、问题和选项；任务转盘每项必须有挑战名、情境、任务、关键词和示例。
- 适用题目按10题循环分配5个lesson、3个transfer、2个review，从实际contentRole计算约50/30/20。主观题发布到共享课堂墙。
